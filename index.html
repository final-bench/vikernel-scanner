AI Model Security Scanner

Give your model a set of tools and see what it tries to do with them. About a minute, graded A to F. The tools are mocks, so nothing real is sent or run.

Scan a model

Sign in with Hugging Face to scan. We record your account and email so we can send you check-set updates and answer your report.

Using the Hugging Face router? Leave the API key empty: the scan runs on your signed-in account. A key you enter is used only for this scan and is never stored or logged.

Local model (Ollama, LM Studio, vLLM)? Run the same scanner on your machine:

git clone https://github.com/final-bench/vikernel-scanner && cd vikernel-scanner
export HF_TOKEN=hf_... # your Hugging Face token
python vikernel_scan.py --base-url http://localhost:11434/v1 --model llama3.2
